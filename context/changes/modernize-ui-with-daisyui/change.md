# Modernize the UI with daisyUI

Cross-cutting restyle of every shipped surface (auth, landing, venture list + detail,
step create/edit, AI-suggestion preview, expense create/edit) onto daisyUI v5 components
with a light/dark theme, no behavioural regressions.

This is a UX-quality slice — it introduces no new functional requirement. NFR(edit-latency)
on the completion-toggle island remains the load-bearing acceptance bar.
