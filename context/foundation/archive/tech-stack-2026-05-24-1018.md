## Why this stack

A solo builder shipping GOAITracker on a 3-week after-hours budget needs a
batteries-included framework that absorbs auth, per-user data isolation, and
the venture/step/expense data model without a custom assembly job. Laravel
is the recommended default for (web, php) and clears the convention-based,
popular-in-training, and well-documented agent-friendly gates (the typed
gate carries the per-language-family caveat for PHP). Eloquent + migrations
handle the data layer; built-in auth covers FR-001/002/003; queues are
available if the one-shot AI step-suggestion call (FR-008) ever needs to
move off the request path. Render was picked over the Fly default for a
simpler PaaS experience with a PostgreSQL add-on; CI runs on GitHub Actions
with auto-deploy on merge to main, which fits the solo + short-timeline
profile. Bootstrapper confidence is verified, so scaffolding should be
smooth. Payments, realtime, and background jobs are out of scope per PRD
non-goals.
